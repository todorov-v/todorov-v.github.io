Installing Ansible Automation Platform 2.5.5 (Containerized)

Chapter 1: Ansible Automation Platform Containerized Installation

This guide explains the process of installing the containerized version of Ansible Automation Platform (AAP) 2.5.5. Follow these steps on a fresh RHEL-based system with administrative access.

System Preparation

  1. Set the Hostname: 
    hostnamectl set-hostname aap
  2. Register the System: 
    
subscription-manager register
subscription-manager refresh
  3. Update the System: 
    dnf update -y
  4. Install Required Tools: 
    
dnf install wget tar git rsync ansible-core -y
sudo dnf install podman -y

Create a User for AAP

  1. Add and Configure the User: 
    
useradd aap
passwd aap
usermod -aG wheel aap
loginctl enable-linger aap
  2. Set Up SSH Access for the User: 
    
ssh-keygen
ssh-copy-id localhost

Prepare the Manifest File

  1. Copy the Manifest File: 
    
sudo cp /root/manifest_ansible_manifest_20241125T125115Z.zip /home/aap/
  2. Set Proper Permissions: 
    sudo chmod 777 /home/aap/manifest_ansible_manifest_20241125T125115Z.zip

Download and Extract the Installer

  1. Extract the Installer: 
    
tar zxvf ansible-automation-platform-containerized-setup-bundle-2.5-5-x86_64.tar.gz
cd ansible-automation-platform-containerized-setup-bundle-2.5-5-x86_64
  2. Set the Collections Path: 
    export ANSIBLE_COLLECTIONS_PATH=/home/aap/ansible-automation-platform-containerized-setup-bundle-2.5-5-x86_64/collections

Edit the Inventory File

Edit the inventory file to customize it for your environment:

vi inventory

Run the Installation

  1. Execute the Installation Playbook: 
    ansible-playbook -i inventory ansible.containerized_installer.install -K
  2. Uninstallation (if needed): 
    ansible-playbook -i inventory ansible.containerized_installer.uninstall -K

With the installation complete, you can now start leveraging the capabilities of Ansible Automation Platform 2.5.5. Stay tuned for further chapters exploring its powerful features!
